💬 토크메이트 TalkMate

OpenRouter API 키를 입력해 주세요

토크메이트는 OpenRouter를 통해 Claude Sonnet 5.5, GPT-6 Luna, Gemini 3.8 Flash를 사용합니다. 키는 openrouter.ai/keys에서 만들 수 있습니다.

  • 키는 OpenRouter 외에는 어디에도 보내지 않으며, 저장 파일(PDF·Word·Excel)에도 들어가지 않습니다.
  • OpenRouter 대시보드에서 키의 사용 한도(크레딧 한도)를 정해 두면 더 안전합니다.
  • 음성 인식은 Microsoft Edge(PC)와 삼성 인터넷·크롬(안드로이드)에서 동작합니다. 음성 인식을 위해 음성이 브라우저 제공사(마이크로소프트·구글) 서버로 전송될 수 있습니다.
진행 중이던 대화가 있습니다.
파일을 직접 열면(file://) 마이크 권한이 거부될 수 있습니다. GitHub Pages 주소나 로컬 서버(python -m http.server)로 열어 주세요.
