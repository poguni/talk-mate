OpenRouter API 키

키는 openrouter.ai/keys에서 만들 수 있습니다.

  • 키는 OpenRouter 외에는 어디에도 보내지 않고, 저장 파일(PDF·Word·Excel)에도 넣지 않습니다.
  • 음성 인식은 Edge(PC)·삼성 인터넷(갤럭시)에서 동작하며, 음성이 브라우저 회사(마이크로소프트·구글) 서버로 전송될 수 있습니다.
  • OpenRouter 대시보드에서 키의 사용 한도를 정해 두면 더 안전합니다.
