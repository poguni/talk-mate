# TalkMate 디자인 가이드 (DESIGN.md)

> 이 문서는 Claude Code가 토크메이트(TalkMate)를 구현하거나 다듬을 때 따르는 시각 디자인 명세입니다.
> 기능 명세는 `../prd-conversation-partner.md`(PRD v0.2)를 따르고, 이 문서는 **어떻게 보이고 느껴져야 하는지**를 정합니다.
> 화면 시안: `design-mockup.html` (브라우저로 열면 7개 화면을 오가며 볼 수 있고, 위쪽 버튼으로 밝은·어두운 테마를 바꿔 볼 수 있습니다)

---

## 1. 콘셉트: Café Notebook (카페 회화 노트)

**카페에서 원어민 친구와 이야기하고, 옆자리 선생님이 내 공책에 빨간 펜으로 첨삭해 주는 장면.**
따뜻한 크림색 바탕 위에 말풍선이 오가고, 내가 한 말 아래에는 줄 공책 한 장이 붙습니다.

| 모티프 | 앱에서의 쓰임 |
|---|---|
| 줄 공책(파란 줄 + 빨간 여백선) | 문장별 교정 카드(첨삭 노트), 리포트의 교정 노트 |
| 빨간 펜(손글씨) | 틀린 부분 위에 고친 단어, 선생님 한마디 |
| 형광펜 | 더 자연스러운 표현, 꼭 외울 표현 |
| 카페 스탬프 카드 | 미션 달성 표시 |
| 카페 주문서 | 연습 설정 화면의 요약('오늘의 주문서') |
| 영수증 | AI 사용 비용 |
| 만년필 잉크(파랑) | 주요 버튼, 내 말풍선, 마이크 |

### 디자인 원칙
1. **대화는 말풍선, 첨삭은 공책.** 말풍선은 깨끗하게 두고, 교정 정보는 모두 공책 카드에 모읍니다. 말풍선 안에 교정 표시를 섞지 않습니다.
2. **빨간 펜은 틀린 곳에만.** `--pen`은 틀린 부분, 오류 집계, 마이크가 듣는 중일 때만 씁니다. 경고·삭제 버튼 글자색(`.btn.danger`)이 유일한 예외입니다.
3. **형광펜은 외울 것에만.** `--hl`은 '더 자연스러운 표현'과 '꼭 외울 표현'에만 칠합니다.
4. **마이크가 주인공.** 회화 화면에서 가장 큰 조작 요소는 마이크입니다(데스크톱 60px, 모바일 68px). 모바일에서는 엄지가 닿는 아래 가운데에 둡니다.
5. **잉크 블루 주요 버튼은 화면당 하나.** 같은 화면에 `.btn.primary`가 여러 개 보이면 하나만 남기고 나머지는 보조 버튼으로 바꿉니다(마이크와 '보내기'는 예외).
6. **장식은 정보가 있을 때만.** 그라데이션 배경, 글로우, 장식용 이모지, 굵은 왼쪽 테두리 카드는 쓰지 않습니다.

## 3. 디자인 토큰

아래 CSS 변수를 `:root`에 넣고, 컴포넌트에서는 HEX 대신 변수만 씁니다.

```css
:root {
  /* ── 바탕과 글자 ── */
  --bg:          #F6F1E7;  /* 페이지 바탕(카페 크림) */
  --surface:     #FFFDF8;  /* 카드, 패널, AI 말풍선 */
  --surface-2:   #F0E9DB;  /* 세그먼트 바탕, 칩, 번역 상자 */
  --surface-3:   #E8DFCC;  /* 아바타, 스켈레톤 */
  --line:        #E3DACA;  /* 기본 테두리 */
  --line-strong: #CFC3AD;  /* 입력·보조 버튼 테두리, 점선 스탬프 */
  --text:        #22252E;
  --text-2:      #454A55;  /* 본문 보조 */
  --muted:       #6B675D;  /* 설명, 메타 (대비 5.0:1) */

  /* ── 문구 도구 ── */
  --ink:        #2B48C8;  /* 잉크 블루: 주요 버튼, 내 말풍선, 마이크, 포커스 */
  --ink-hover:  #2340B5;
  --ink-soft:   #E5E9FA;  /* 선택된 카드 바탕 */
  --on-ink:     #FFFFFF;
  --pen:        #C93A29;  /* 빨간 펜: 틀린 곳, 오류 집계, 듣는 중 */
  --pen-soft:   #FBE4DE;
  --fix:        #1F7F53;  /* 고친 문장, '정확' */
  --fix-soft:   #DFF2E6;
  --hl:         #FFE27A;  /* 형광펜 띠 */
  --hl-soft:    #FFF3BF;
  --note:        #FFFCF3; /* 공책 종이 */
  --note-line:   #D6E0F0; /* 공책 파란 줄 */
  --note-margin: #EDB3AA; /* 공책 빨간 여백선 */
  --stamp:       #2B48C8; /* 미션 스탬프 */

  /* ── 언어 (배지 전용) ── */
  --lang-en: #3559C7;  --lang-ja: #B03F69;  --lang-es: #9C600B;

  /* ── 그림자 ── */
  --shadow-1: 0 1px 0 rgba(70,50,20,.05), 0 8px 24px rgba(70,50,20,.07);
  --shadow-2: 0 2px 0 rgba(70,50,20,.06), 0 18px 48px rgba(70,50,20,.16);

  /* ── 글꼴 ── */
  --font-body: 'IBM Plex Sans KR', 'Noto Sans JP', system-ui, -apple-system, 'Malgun Gothic', sans-serif;
  --font-pen:  'Nanum Pen Script', 'IBM Plex Sans KR', cursive;
  --font-mono: 'JetBrains Mono', ui-monospace, Consolas, monospace;

  /* ── 반경 ── */
  --r-input: 12px; --r-chip: 999px; --r-card: 18px; --r-bubble: 20px; --r-sheet: 24px;
}

/* 어두운 테마: '밤 카페' */
:root[data-theme="dark"] {           /* 시스템 설정을 따를 때는 아래 미디어 쿼리에도 같은 값 */
  --bg: #14120E; --surface: #1D1A15; --surface-2: #28241D; --surface-3: #332E25;
  --line: #353026; --line-strong: #4A4335;
  --text: #F2EDE3; --text-2: #D6CFC2; --muted: #A69E8F;
  --ink: #8FA3FF; --ink-hover: #A7B6FF; --ink-soft: #252C4D; --on-ink: #0E1330;
  --pen: #FF8371; --pen-soft: #3B201B;
  --fix: #6CD49C; --fix-soft: #16301F;
  --hl: #6B5413; --hl-soft: #3A3218;     /* 어두운 바탕에서는 진한 겨자색 띠 + 밝은 글자 */
  --note: #201D17; --note-line: #2C3546; --note-margin: #5B2F29;
  --lang-en: #8FA8FF; --lang-ja: #F08DB3; --lang-es: #F2B35A;
  --stamp: #8FA3FF;
  --shadow-1: 0 1px 0 rgba(0,0,0,.3), 0 8px 24px rgba(0,0,0,.25);
  --shadow-2: 0 2px 0 rgba(0,0,0,.35), 0 18px 48px rgba(0,0,0,.45);
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* 위 dark 값과 동일하게 */ }
}
```

### 색 사용 규칙
- **잉크·펜·체크·형광펜은 의미가 고정**입니다. 잉크=행동, 펜=틀림, 체크(`--fix`)=맞음·고친 결과, 형광펜=외울 것. 다른 용도로 빌려 쓰지 않습니다.
- **언어 색**은 언어 배지(EN/JA/ES)에만 씁니다. 버튼·말풍선·차트에는 쓰지 않습니다.
- 어떤 색 구분이든 **글자를 함께** 표시합니다(오류 칩의 '성·수 일치', 스탬프 옆 미션 문장, 배지 안의 EN).
- 내 말풍선(`--ink` 바탕) 위 글자는 `--on-ink`만 씁니다.

## 4. 타이포그래피

Google Fonts에서 불러옵니다.

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+KR:wght@400;500;600;700&family=Nanum+Pen+Script&family=JetBrains+Mono:wght@400;600&family=Noto+Sans+JP:wght@400;700&display=swap">
```

| 역할 | 글꼴 | 크기/굵기 | 쓰임 |
|---|---|---|---|
| Display | IBM Plex Sans KR | 40 / 700, 자간 -0.035em | 시작 화면 제목 |
| Page | IBM Plex Sans KR | 28 / 700, -0.03em | 리포트 제목 |
| Section | IBM Plex Sans KR | 18 / 700, -0.02em | 카드 제목 |
| Bubble | IBM Plex Sans KR (+ Noto Sans JP) | 17 / 400, 줄 간격 1.55 (모바일 16) | 말풍선, 교정 원문 |
| Body | IBM Plex Sans KR | 16 / 400, 1.6 | 일반 본문 |
| Small | IBM Plex Sans KR | 13–14 / 400–600 | 설명, 메타, 칩 |
| Pen | Nanum Pen Script | 22–26 / 400, -3° 기울임 | 고친 단어, 선생님 한마디 |
| Mono | JetBrains Mono | 12–28 / 400–600 | 비용, 숫자 통계, 모델 ID, 영수증, eyebrow 라벨 |

- **외국어 문장에는 `lang` 속성**(`lang="es"`, `lang="ja"`, `lang="en"`)을 붙입니다. 브라우저가 알맞은 글꼴과 줄바꿈을 고르고, 화면 읽기 프로그램이 올바르게 발음합니다.
- **Pen 글꼴은 한글과 기본 라틴 문자 전용**입니다. Nanum Pen Script에는 일본어 글자가 없으므로, **일본어 교정 단어는 Body 글꼴 600 + `--pen` 색**으로 씁니다. 스페인어 강세 문자(á, é, ñ)는 표시되지만 획이 어색하면 같은 방식으로 바꿉니다.
- 한국어 본문은 `word-break: keep-all`로 단어 중간에서 줄이 바뀌지 않게 합니다.

## 5. 레이아웃

### 5.1 앱 셸
- 상단 바(높이 약 60px): 왼쪽 로고(잉크 블루 말풍선 마크 + '토크메이트'), 오른쪽 비용 칩(회화·리포트 화면에서만) + 설정 버튼.
- 본문 최대 너비 1200px, 좌우 여백 32px(모바일 16px).
- **회화·리포트**: 본문 + 오른쪽 레일(300px) 2단. 860px 이하에서 1단으로 바뀌고, 레일 내용은 아래 5.3처럼 압축됩니다.
- **연습 설정**: 본문 + 오른쪽 주문서(320px, `position: sticky`).

### 5.2 표면 계층
| 단계 | 토큰 | 예 |
|---|---|---|
| 바탕 | `--bg` | 페이지, 회화 영역 안쪽 |
| 카드 | `--surface` + `--line` + `--shadow-1` | 설정 카드, 레일 카드, AI 말풍선 |
| 종이 | `--note` + 줄무늬 | 첨삭 노트, 주문서, 영수증 |
| 떠 있는 층 | `--surface` + `--shadow-2` | 설정 대화 상자, 힌트 시트, 주문서 |

### 5.3 모바일(360px 기준)
- 상단: 상황 타일 + 제목 + 턴, 오른쪽 '리포트' 버튼.
- 그 아래 **미션 띠**: 작은 스탬프 원 4개 + '미션 2/4' + 비용(원). 누르면 미션 목록이 펼쳐집니다.
- 하단 고정 **도크**: 입력창 한 줄, 그 아래 [힌트] · 마이크(68px) · [보내기] 3칸 배치.
- 힌트는 **아래에서 올라오는 시트**(둥근 모서리 24px, 뒤 배경 어둡게)로 엽니다.

## 6. 컴포넌트 명세

괄호 안은 시안의 클래스 이름입니다.

### 6.1 언어 배지 (`.lang.en/.ja/.es`)
- 지름 36px(작게 24px) 원, Mono 600 대문자 2글자(EN·JA·ES), 흰 글자.
- **국기 이모지를 쓰지 않습니다.** Windows의 Edge는 국기 이모지를 'US', 'JP' 같은 글자로 보여 주기 때문입니다.

### 6.2 선택 카드 (`.pick`)
- 반경 16px, 테두리 1.5px `--line`. 선택되면 테두리 `--ink`, 바탕 `--ink-soft`, 오른쪽 위에 22px 체크 원.
- 언어 카드: 배지 + '영어 · English' + 현재 수준. 상황 카드: 44px 아이콘 타일(`.tile`) + 제목 + 설명 1줄.
- `<button aria-pressed>`로 만듭니다.

### 6.3 세그먼트 (`.seg`, `.seg.ink`)
- 알약 모양 바탕 `--surface-2`, 안쪽 버튼 높이 36px.
- 기본: 선택 항목이 흰 알약으로 떠오름. `.seg.ink`: 선택 항목을 잉크 블루로 채움(수준, 키 보관 방식처럼 결과가 중요한 선택).

### 6.4 오늘의 주문서 (`.ticket`)
- 종이 표면, 위쪽에 잉크 블루 점선 띠(주문서 절취 느낌). 'TODAY'S ORDER' Mono 라벨 → 상황 이름(22/700) → 언어·장소·상대·목표 정의 목록 → 미션 번호 목록 → 모델 구성 세그먼트 → 예상 비용(Mono 20) → '대화 시작하기' 큰 주요 버튼.

### 6.5 말풍선 (`.msg.ai`, `.msg.me`)
- AI: `--surface`, 테두리, 왼쪽 위 모서리 6px(나머지 20px), 위에 아바타(역할 첫 글자) + 역할 이름. 아래에 도구 버튼(`.tool`): 듣기 · 번역.
- 나: `--ink` 바탕, 오른쪽 위 모서리 6px.
- 번역(`.tr`): 말풍선 아래 `--surface-2` 상자, 14px.
- AI가 답을 만드는 중: 말풍선 안에 점 3개(`.typing`).

### 6.6 첨삭 노트 (`.note.fix`, `.note.ok`) ★ 핵심
- 내 말풍선 바로 아래, 최대 너비 560px, 반경 `4px 16px 16px 16px`(말풍선과 이어진 느낌).
- 바탕: `--note` + 32px 간격 파란 줄(`--note-line`) + 왼쪽 30px 위치 빨간 여백선(`--note-margin`). **모든 줄의 `line-height`는 32px**로 맞춰 글자가 줄 위에 앉게 합니다.
- 구성(위에서 아래로):
  1. 머리: 연필 아이콘 + '고칠 곳 N'(`--pen`) + 대표 오류 유형 배지. 오류가 없으면 체크 아이콘 + '완벽해요'(`--fix`) + '정확' 배지.
  2. 원문(17px): 틀린 부분은 `.mark` — 가운데 2px 빨간 취소선 + 바로 위에 Pen 글꼴로 고친 단어(-3° 기울임).
  3. 고친 문장: '→' + 전체 문장(`--fix`, 600) + 듣기 버튼.
  4. 이유: 오류 유형 칩(`.chip.pen`) + 한국어 설명 1줄.
  5. 더 자연스럽게: 라벨 + 형광펜 칠한 표현(`.hl`) + 듣기 버튼.
  6. 선생님 한마디(`.pen-comment`): Pen 글꼴 22px. 칭찬이나 미션 달성 소식도 여기에 씁니다(정확한 문장은 `--fix` 색).
- 불러오는 중(`.note.loading`): 공책 바탕 + 스켈레톤 막대 2개.

### 6.7 미션 스탬프 카드 (`.stamps`, `.stamp`)
- 미완료: 38px 점선 원 + 번호(Mono).
- 완료: 2px `--stamp` 실선 원 + 체크, -12° 회전, 옅은 잉크 바탕. 옆 미션 문장은 `--muted`.
- 카드 제목 오른쪽에 '2 / 4'(Mono).

### 6.8 빨간 펜 집계 (`.bars`)
- 오류 유형 이름(84px) · 막대(높이 8px, `--pen`) · 횟수(Mono). 가장 많은 유형이 100%.
- 차트 라이브러리를 쓰지 않습니다. 인쇄(PDF)에서도 보이도록 `print-color-adjust: exact`.

### 6.9 영수증 (`.receipt`)
- 종이 바탕, Mono 12px, 아래쪽 톱니 모양 가장자리(CSS mask).
- '— RECEIPT —' → 역할·모델(짧은 이름)·호출 수 / 금액 → 점선 → 합계(달러 · 원).

### 6.10 마이크 (`.mic`, `.mic.live`)
- 기본: 잉크 블루 원(데스크톱 60px, 모바일 68px), 마이크 아이콘 26px, 잉크색 그림자.
- 듣는 중(`.live`): `--pen` 바탕 + 8px `--pen-soft` 고리 + 정지 아이콘. 입력창 테두리도 `--pen`, 아래에 파형 막대 5개(`.wave`) + '듣고 있어요 · 다시 누르면 멈춰요'.
- 인식 중인 글자는 확정 부분은 `--text`, 아직 확정되지 않은 부분은 `--muted`.
- `aria-label`: '음성 입력' / '음성 입력 멈추기'.

### 6.11 입력 바 (`.composer` > `.inbar`)
- 입력창과 [마이크] [힌트] [보내기]를 **하나의 둥근 바**(반경 30px, 테두리 1.5px `--line-strong`, 바탕 `--bg`)에 담습니다. 입력창·버튼의 높이는 모두 `--h`(PC 48px)로 맞춥니다.
- 마이크: 지름 48px 원(`--ink`). 힌트: 48px 알약, `--ink-soft` 바탕 + `--ink` 글자 + 전구 아이콘. 보내기: 48px 알약, `--ink` 바탕 + 화살표 아이콘.
- 입력창은 테두리 없이 바 안에 놓이고, 글이 길어지면 최대 160px까지 늘어납니다. 이때 버튼들은 바의 아래쪽에 붙어 있습니다.
- 상태: 입력 중에는 바 테두리 `--ink` + 4px `--ink-soft` 고리, 듣는 중에는 테두리 `--pen` + 4px `--pen-soft` 고리.
- 안내 문구(마이크 상태)는 바 바깥 아래에 12px로 둡니다.
- 모바일(860px 이하): 바 안에서 입력창이 위 줄 전체를 쓰고, 아래 줄에 [마이크 56px] [힌트(가운데)] [보내기]를 둡니다.
- AI가 답하는 중에는 '보내기'를 비활성으로 두고 글자를 '응답 중…'으로 바꿉니다(입력은 계속 가능).
- AI가 답을 마치면, 입력창에 방금 보낸 문장이 남아 있을 경우 비우고 PC에서는 바로 입력할 수 있게 커서를 둡니다.

### 6.12 힌트 (데스크톱 패널, 모바일 `.sheet`)

### 6.13 통계 타일 (`.stat`)

## 10. 모션
- 기본 지속 시간 180–300ms, 이징 `cubic-bezier(0.2, 0.8, 0.2, 1)`.
- **말풍선 도착**: 8px 아래에서 올라오며 나타남(opacity 0→1, 220ms).
- **첨삭 노트**: 말풍선 뒤 120ms 늦게, 위에서 아래로 펼쳐짐(`clip-path` 또는 높이). 고친 단어(Pen)는 마지막에 페이드 인.
- **스탬프 찍기**: 미션 달성 시 1.2배 → 1배, 회전 0° → -12°(200ms).
- **듣는 중**: 파형 막대가 1초 주기로 오르내림, 마이크 고리가 은은히 맥박.
- `prefers-reduced-motion: reduce`에서는 모든 움직임을 끄고 즉시 바꿉니다.

## 12. 접근성 체크리스트
- 텍스트 대비 4.5:1 이상. `--muted`(#6B675D, 바탕 대비 5.0:1)보다 옅은 글자색은 만들지 않습니다.
- 모든 조작은 실제 `<button>`, `<a href>`, `<input>`, `<select>`, `<label>`로 만듭니다. 선택 카드·세그먼트는 `aria-pressed`, 스위치는 `role="switch"` + `aria-checked`.
- 터치 영역 최소 44×44px(도구 버튼은 높이 32px이지만 좌우 여백을 포함해 44px 이상 간격).
- 색으로만 구분하지 않기: 틀린 곳은 취소선 + 색, 스탬프는 체크 아이콘 + 색, 배지는 글자 + 색.
- 외국어에는 `lang` 속성. 대화 목록은 `aria-live="polite"`.
- 포커스 링: 2px `--ink`, 오프셋 2px.
